What does dynamic mean?

Dynamic storage can grow or shrink while a program runs. Some array implementations have a fixed size, while dynamic arrays can resize.

🔒

Static

Stack Queue Linked List

Your note labels these as Static.

Important clarification

Static/dynamic describes storage allocation or size behaviour. Stack, queue, and linked list describe data structures. They can be implemented with different storage approaches. Keep your original labels for your notes, but remember that the categories are not universally fixed.

Time and Space Complexity

Your notes introduce both time and space complexity.

⏱️

Time Complexity

Describes how the amount of work an algorithm performs grows as its input size increases.

We commonly express it using Big O notation.
💾

Space Complexity

Describes how the memory required by an algorithm grows as the input size increases.

Time is about computational work; space is about memory.
